{% trans "Understanding E-Waste" %}

{% trans "Electronic waste (e-waste) is any discarded electrical or electronic device. In a world driven by technology, knowing how to manage these items is vital for our planet." %}

{% trans "The Problem" %}

{% blocktrans %} Electronic devices contain toxic substances like lead, mercury, and cadmium. When disposed of in regular landfills, these chemicals leak into the soil and water, affecting ecosystems and human health. {% endblocktrans %}

{% trans "Recycling e-waste helps conserve natural resources and reduces the environmental impact of electronic manufacturing." %}

{% trans "Small Household Appliances" %}

{% trans "Includes vacuum cleaners, toasters, coffee machines, and electric toothbrushes." %}

{% trans "How to discard:" %} {% trans "Take these to specialized e-waste bins at supermarkets or municipal recycling centers." %}

{% trans "Large Household Appliances" %}

{% trans "Includes washing machines, fridges, air conditioners, and microwaves." %}

{% trans "How to discard:" %} {% trans "Request a pick-up from your local municipality or use the 'one-for-one' rule when buying a new one." %}

{% trans "IT and Telecommunications" %}

{% trans "Includes computers, laptops, tablets, smartphones, printers, and network routers." %}

{% trans "Data Privacy First!" %}
{% trans "Before recycling, ensure you perform a factory reset. For computers, use a secure erase tool to delete all data." %}
{% trans "Learn How" %}
{% trans "How to discard:" %}
  • {% trans "Small items like phones andtablets can go into specialized e-waste bins at retail stores." %}
  • {% trans "For medium items like desktops or printers, use our EcoMap to find industrial recycling centers." %}

{% trans "Batteries and Accumulators" %}

{% trans "Includes alkaline batteries, Li-ion phone batteries, Powerbanks and car batteries." %}

{% trans "Critical:" %} {% trans "Never throw batteries in the general trash. They are highly flammable and corrosive." %}
{% trans "How to discard:" %}
  • {% trans "Use 'Pilhão' containers found in most supermarkets and pharmacies." %}
  • {% trans "For swollen or damaged batteries, place them in a bag with sand or vermiculite before disposal." %}
  • {% trans "Car batteries must be returned to automotive service centers or specialized scrapyards." %}
